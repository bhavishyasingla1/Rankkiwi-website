Export & Downloads

Export & Media Downloads

Keep your research organized with clean, zero-friction export actions to native Excel (.xlsx), CSV, JSON, and rich clipboard tables, plus high-fidelity media downloads.

Take your research anywhere: Rank Kiwi allows you to export entire analyzed datasets to native Excel (.xlsx) spreadsheets, standard CSV files, developer-friendly JSON schemas, or rich Clipboard pastes (TSV and formatted HTML tables). You can also download verified MP4 video streams of Instagram Reels (individually or in batch queues) and high-resolution thumbnail images from YouTube videos directly to your browser's default downloads destination.

Export Options Overview

All export actions are accessible directly from the Rank Kiwi header toolbar or the Export Menu dropdown once your analysis finishes collecting posts:

📗 Native Excel (.xlsx)

Generates genuine Open Packaging Conventions XML workbooks in-memory using a lightweight, zero-dependency PKZIP Store archive engine. Opens seamlessly in Microsoft Excel and Apple Numbers with pre-formatted number headers.

📊 CSV File (.csv)

Best for Google Sheets, Airtable, and command-line data pipelines. Formatted with standard RFC 4180 comma separation and quoted text strings with formatted publish dates.

📦 JSON File (.json)

Best for automated workflows, Python Pandas notebooks, LLM prompt inputs, and internal research databases. Preserves full metadata, creator baselines, and nested items.

📋 Rich Clipboard Copy

Simultaneously writes tab-separated text (TSV) and styled HTML tables to your clipboard for instant, frictionless pasting directly into Google Sheets, Excel, Notion, or Slack.

Excel Export (.xlsx Spreadsheets).

Selecting Export Excel (.xlsx) from the toolbar generates a true, binary Open Packaging Conventions XML workbook directly inside your browser. Unlike extensions that simply rename a CSV file to .xlsx (which triggers Microsoft Excel corruption warnings), Rank Kiwi packages authentic XML spreadsheet parts (workbook, worksheet, shared strings, styles, and relationships) using an in-memory, zero-dependency PKZIP Store archive engine.

Why Native .xlsx Matters

  • No Warning Prompts: Opens instantly in Microsoft Excel, Apple Numbers, LibreOffice, and Google Drive without security warnings or format mismatch errors.
  • Preserved Numeric Types: View counts, like counts, comment counts, and Outlier Scores are stored as genuine numbers, ready for immediate formulas, pivot tables, and conditional formatting.
  • Pre-Formatted Date Fields: Publication dates are formatted cleanly (MMM D, YYYY), avoiding timezone truncation or localized parsing errors.
  • Standard File Naming: Downloaded files follow the clean convention rankkiwi-[creator]-[platform]-[timestamp].xlsx.

CSV Export (Plain Spreadsheets).

Clicking Export CSV compiles all currently filtered posts into a UTF-8 encoded, RFC 4180-compliant .csv file and automatically initiates a browser download named rankkiwi-[creator]-[platform]-[timestamp].csv.

Exported Columns Reference

Every row in the CSV corresponds to one analyzed post or video. The exported fields include:

Column Header Data Type Description Example
rank Integer Current position in the workspace based on your active sort order 1
title_or_caption String (Quoted) Full caption text or video title with escaped quotes and linebreaks "5 mistakes you are making with hooks..."
url URL String Direct URL to the public Reel, video, or Short https://instagram.com/reel/C8xyz...
views Integer Total public views or plays recorded at scan time (empty if hidden) 482100
likes Integer Public like count (empty or 0 if hidden by creator) 31200
comments Integer Public comment count recorded from the interface 840
outlier_score Float Multiplier relative to creator's sample median views (e.g. 4.82x) 4.82
engagement_rate Percentage Combined engagements divided by views (where view data is public) 6.65%
posted_date Date String Formatted publication date (MMM D, YYYY) Feb 14, 2026
content_type String Content taxonomy: reel, video, or short reel
Tip for Google Sheets: To import your CSV into Google Sheets, navigate to File > Import > Upload. Choose "Detect automatically" for separator type. The numeric view counts and Outlier Scores will format as native numbers ready for charting.

Instant Clipboard Export.

Don't need a file saved to disk? Click Copy to Clipboard from the toolbar. Rank Kiwi writes dual payloads to your operating system clipboard simultaneously:

  1. Tab-Separated Values (text/plain): Clean, unstyled tab-delimited text for command-line tools and plain-text editors.
  2. Formatted HTML Table (text/html): Rich HTML table data containing styled headers and formatted values.

When you press Cmd + V (Mac) or Ctrl + V (Windows), your destination software picks the optimal format:

  • Google Sheets & Microsoft Excel: Automatically splits into table cells across rows and columns without triggering an import wizard.
  • Notion: Pastes directly as an editable Notion database table with pre-configured columns.
  • Airtable: Populates columns directly inside your existing Grid views.

Download Instagram Reels (MP4).

Rank Kiwi provides direct MP4 video downloading for analyzed Instagram Reels. You can download individual Reels from the Detail Inspector modal or trigger batch downloads from the toolbar.

1. Single Reel Download

Click any card to open the Content Detail Modal. Click the Download Reel (MP4) button. Rank Kiwi resolves the verified CDN video source and initiates a browser download via Chrome's downloads API.

2. Batch Reel Downloads

Use the checkboxes in the workbench grid to select multiple Reels (or click Select All in the toolbar), then click Download Selected. Rank Kiwi queues the downloads sequentially, preventing network congestion while preserving full video quality.

Filesystem-Safe Naming Convention

Every downloaded Reel is saved to your default Chrome Downloads folder with sanitized naming:

rankkiwi_{creator}_{reelId}.mp4

All illegal filesystem characters, path traversal sequences (../), and control characters are stripped automatically before calling the browser download manager.

Binary Magic-Byte Validation

Before initiating a download, Rank Kiwi checks the media response payload's magic bytes to ensure it is a genuine MP4 video file. If Instagram returns an HTML redirect or login gate, the download is safely aborted with a clear notification rather than saving a corrupt file.

Chrome Download Preferences: If you have "Ask where to save each file before downloading" enabled in your Chrome browser settings (chrome://settings/downloads), Chrome will prompt you for a save directory on each item during batch downloads. To save directly to your Downloads folder without prompts, toggle that setting off in Chrome.

Download YouTube Thumbnails (HD).

Thumbnails are critical for video research. Rank Kiwi allows you to save creator thumbnails at the highest possible production resolution uploaded to YouTube's public CDN.

Resolution Hierarchy

Rank Kiwi uses a smart fallback sequence to acquire the crispest available image:

  1. maxresdefault.jpg (1920×1080): Full HD production thumbnail uploaded by the creator.
  2. sddefault.jpg (640×480): Standard definition fallback for older or smaller uploads.
  3. hqdefault.jpg (480×360): High-quality universal fallback ensuring downloads never fail.

To download, click any video card in the workbench to open the inspector, then click Download HD Thumbnail. The file is saved directly to your browser's default downloads destination.

YouTube Terms & Compliance Policy

Strict Stream Protection: Rank Kiwi is committed to platform policy compliance.
  • Zero Video/Audio Downloading on YouTube: In strict compliance with YouTube Terms of Service and Chrome Web Store Developer Policies, Rank Kiwi never downloads YouTube video streams or audio files.
  • Public Thumbnails Only: Thumbnail downloads strictly retrieve static, publicly accessible image assets directly from YouTube's official CDN (i.ytimg.com).
  • First-Party Watch Links: Video previews and playback for YouTube content are accessible via direct links to official YouTube watch pages.

Fair Use & Responsible Usage

Rank Kiwi is built strictly for creator research, editorial benchmarking, hook analysis, and building educational swipe files.

Legal & Ethical Responsibility:
  • Respect Intellectual Property: Downloading a Reel or thumbnail for private analytical study, pacing breakdown, or hook deconstruction is standard research practice under fair use.
  • Never Re-upload: Never repost, republish, or commercialize another creator's video or thumbnail without explicit written permission.
  • Create Original Content: Use outlier insights to understand what topics and structural pacing resonate with audiences, then craft your own unique angle and perspective.
