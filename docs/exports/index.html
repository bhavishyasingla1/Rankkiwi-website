Export Options Overview

All export actions are accessible directly from the Rank Kiwi header toolbar once your analysis finishes collecting posts:

📊 CSV File (.csv)

Best for Google Sheets, Microsoft Excel, Apple Numbers, and Airtable. Formatted with standard comma separation and quoted text strings.

📦 JSON File (.json)

Best for automation pipelines, Python data notebooks, LLM prompt inputs, and internal research databases. Preserves raw nested objects.

📋 Clipboard Copy

Best for instant pasting directly into Notion tables, Google Docs briefs, or Slack channels without downloading files.

CSV Export (Spreadsheets)

Clicking Export CSV in the Rank Kiwi workspace compiles all currently filtered posts into a UTF-8 encoded .csv file and automatically initiates a browser download named rankkiwi-[creator]-[platform]-[timestamp].csv.

Exported Columns Reference

Every row in the CSV corresponds to one analyzed post or video. The exported fields include:

Column Header Data Type Description Example
rank Integer Current position in the workspace based on your chosen sort order 1
title_or_caption String (Quoted) Full caption text or video title with escaped linebreaks "5 mistakes you are making with hooks..."
url URL String Permanent link to the specific post, Reel, or video https://instagram.com/reel/C8xyz...
views Integer Total public views or plays recorded at the time of scan 482100
likes Integer Public like count (empty or 0 if hidden by creator) 31200
comments Integer Public comment count recorded from the interface 840
outlier_score Float Multiplier relative to creator's median views in sample 4.82
engagement_rate Percentage Combined engagements divided by views (where available) 6.65%
posted_date ISO-8601 Date Date of original publication (YYYY-MM-DD) 2026-02-14
content_type String Content taxonomy: reel, video, short reel
Tip for Google Sheets: To open your CSV in Google Sheets, go to File > Import > Upload. Select the CSV, and choose "Detect automatically" for separator type. The numeric view counts and Outlier Scores will format as native numbers ready for charting.

JSON Export (Structured Data)

Selecting Export JSON produces a clean JSON document containing analysis metadata alongside the item list. This format is ideal for feeding creator data directly into AI assistants (Claude, ChatGPT) to perform qualitative hook analysis.

Clipboard Export (Quick Paste)

Don't need a file on your hard drive? Click Copy to Clipboard. Rank Kiwi writes a formatted, tab-delimited table directly into your operating system clipboard.

You can immediately press Cmd + V (Mac) or Ctrl + V (Windows) in:

  • Notion: Creates an instant multi-column Database with properties already set.
  • Google Sheets & Excel: Automatically parses into cells across rows and columns without an import dialog.
  • Airtable: Pastes directly into an existing Grid view.

Downloading Instagram Reels

When you click on any Reel in your analyzed grid to open its Post Detail Inspector, you will see a Download Reel (MP4) button.

How it works

  1. Rank Kiwi identifies the publicly accessible video element currently embedded in your browser tab's active session.
  2. It streams the high-definition MP4 asset directly from the platform CDN using native Chrome download APIs.
  3. The file is saved to your default Chrome Downloads folder as [handle]-reel-[shortcode].mp4.
Troubleshooting Downloads: If clicking download opens a video player in a new browser tab instead of saving the file, right-click the video and choose "Save Video As...". This happens when Chrome settings are configured to play media in-browser rather than download automatically.

Downloading YouTube Thumbnails

For YouTube video and Shorts research, thumbnails are 50% of the hook equation. Rank Kiwi allows you to save creator thumbnails at maximum available resolution.

Resolution Hierarchy

YouTube generates thumbnails in multiple sizes. Rank Kiwi's download action uses an automatic fallback sequence:

  1. maxresdefault.jpg (1920×1080): The highest available production resolution uploaded by the creator.
  2. sddefault.jpg (640×480): High-standard fallback if the creator uploaded an older or smaller asset.
  3. hqdefault.jpg (480×360): Standard thumbnail fallback ensuring downloads never fail.

To download, open any YouTube video card in the inspector modal and click Download HD Thumbnail.

Fair Use & Responsible Usage

Rank Kiwi is built strictly for research, benchmarking, editorial analysis, and educational swipe files.

Legal & Ethical Responsibility:
  • Respect Copyright: Downloading a Reel or thumbnail for private analytical study, pacing breakdown, or hook deconstruction is standard research practice under fair use doctrine.
  • Never Re-upload: Never repost, republish, or commercialize another creator's intellectual property without explicit permission.
  • Attribute Inventions: When inspired by an outlier's narrative structure, bring your original perspective, voice, and research to your audience.
