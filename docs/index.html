GETTING STARTED

Introduction

Rank Kiwi is a browser extension for researching creator content performance on Instagram and YouTube.

Overview

Rank Kiwi calculates performance benchmarks and Outlier Scores for creator posts directly within your browser. It helps marketers, creators, and researchers find viral formats without manual scraping or data spreadsheets.

Core Principles

  • Client-Side: All analyses execute locally in the browser environment.
  • Zero Authentication: No Rank Kiwi account or login credentials required.
  • No Database Storage: Analyzed creator content is never persisted on external servers.

GETTING STARTED

Your first analysis

Run an analysis on any supported Instagram profile or YouTube channel in three steps.

Execution Steps

  1. Open a creator profile: Navigate to any public Instagram profile (e.g., instagram.com/creator) or YouTube channel in Google Chrome.
  2. Open the Rank Kiwi panel: Click the Rank Kiwi extension icon or sidebar panel.
  3. Select sample size and analyze: Choose how many items to analyze (25, 50, 100, or Custom) and click Analyze.

Tip: For Instagram Reels, navigate directly to the creator's /reels/ tab for maximum metric fidelity.

PLATFORMS

Instagram

Rank Kiwi supports creator research across public Instagram creator and business profiles.

Supported Surfaces

  • Profile Main Grid (Reels, Feed Posts, Multi-image Carousels).
  • Reels Tab (Dedicated short-form video feed).

Supported Metrics

Views (plays), likes, comments, caption text, publication dates, and computed Outlier Scores.

Limitations

Private accounts and content requiring restricted login permissions cannot be analyzed.

PLATFORMS

Instagram Reels

Rank Kiwi analyzes creator Reels and displays available performance metrics.

Supported Pages

Creator profile Reels tabs (instagram.com/[username]/reels/) and main profile grids.

Metrics

  • Play Counts / Views: Total recorded views.
  • Engagement: Like counts and total comments.
  • Outlier Score: Relative multiplier against median Reel performance.
  • Metadata: Caption, post date, and direct URL.

How Analysis Works

Rank Kiwi reads the visible DOM elements, parses structured metric strings, normalizes numeric values, and calculates median benchmarks.

How Sorting Works

Posts can be ordered descending by Outlier Score, Views, Likes, Comments, or chronological order.

Limitations

Metrics reflect publicly visible page data at the moment of inspection.

PLATFORMS

Instagram Posts & Carousels

Analyze single-image posts and multi-slide carousels on creator profiles.

Supported Pages

Creator main profile grid (instagram.com/[username]/).

Metrics

  • Likes and comments.
  • Outlier Score calculated against typical post engagement.
  • Full caption text and slide counts where available.

Limitations

Instagram does not expose view counts on static image posts; Outlier Score on static posts is computed from engagement metrics.

PLATFORMS

YouTube

Rank Kiwi supports channel-level performance research across YouTube Videos and Shorts.

Supported Surfaces

  • Channel Videos tab (youtube.com/@channel/videos).
  • Channel Shorts tab (youtube.com/@channel/shorts).

Supported Metrics

View count, publication date, title, duration, likes, comments, and Outlier Score.

PLATFORMS

YouTube Videos

Analyze long-form video uploads on creator YouTube channels.

Supported Pages

Channel Videos tab (youtube.com/@[handle]/videos).

Metrics

  • Total lifetime view counts.
  • Relative upload age and publish timestamps.
  • Outlier Score against channel median long-form views.

How Analysis Works

Rank Kiwi parses channel metadata, converts formatted view strings (e.g. "1.2M views") into discrete integers, and calculates distributional benchmarks.

PLATFORMS

YouTube Shorts

Analyze vertical short-form video performance on creator YouTube channels.

Supported Pages

Channel Shorts tab (youtube.com/@[handle]/shorts).

Metrics

  • Short view counts.
  • Title and direct link.
  • Outlier Score comparing Shorts specifically to the creator's other Shorts.

Limitations

Shorts benchmarks are calculated separately from long-form video uploads to maintain baseline statistical validity.

SORTING

Views

Usage

Select Views from the Sort dropdown to locate the most-watched content regardless of publication date or baseline follower size.

SORTING

Likes

Order analyzed content descending by total likes.

Usage

Useful for evaluating direct audience appreciation and resonance across image and video formats.

SORTING

Comments

Order analyzed content descending by total comment counts.

Usage

Identifies high-discussion posts, controversial topics, and community-engaging prompts.

SORTING

Outlier Score

Order content by statistical outperformance relative to the creator's typical baseline.

Formula Concept

Outlier Score divides a post's metric by the creator's median metric across the analyzed sample.

Score Multiplier Classification Interpretation
1.0× Typical Matches the creator's expected performance baseline.
3.2× Strong Delivered more than triple the creator's normal engagement.
5.8×+ Outlier Exceptional performance; indicates breakout algorithm distribution.

SORTING

Oldest

Order analyzed content chronologically from oldest to newest.

Usage

Helpful for tracking a creator's evolution, content style transitions, and historical performance changes over time.

FILTERING

Content type

Filter displayed results by specific media formats.

Supported Filters

  • Instagram: All, Reels only, Static Posts only, Carousels only.
  • YouTube: All, Long-form Videos only, Shorts only.

FILTERING

Performance filters

Isolate posts that exceed specific minimum performance thresholds.

Filter Criteria

  • Minimum Outlier Score threshold (e.g., ≥ 2.0×).
  • Minimum view count threshold.
  • Minimum like or comment count threshold.

EXPORTING

Copy as CSV

Copy analyzed results formatted as comma-separated values directly to your clipboard.

Action

Click Copy in the top action bar to place formatted CSV text into the system clipboard, ready to paste into Google Sheets, Excel, or Notion.

EXPORTING

Export CSV

Download a structured .csv spreadsheet file containing all analyzed records.

Included Columns

Post URL, Content Type, Date, Views, Likes, Comments, Outlier Score, and Caption text.

EXPORTING

Export JSON

Download raw structured .json data for programmatic pipelines and automated workflows.

Format

An array of JSON objects with typed keys: url, type, date, views, likes, comments, outlierScore, and caption.

DOWNLOADS

PRIVACY

How Rank Kiwi handles data

Rank Kiwi is built with a client-first, privacy-by-design architecture.

Architecture Principles

  • Local Processing: Analysis algorithms execute inside the browser sandbox on your machine.
  • No Creator Content Database: Rank Kiwi does not upload or maintain a server-side repository of posts you analyze.
  • No Authentication Tokens: Rank Kiwi never accesses or transmits your Instagram or YouTube account credentials.

Read the complete Privacy Policy for full disclosures.

FAQ

Common questions

Answers to frequent technical and product questions.

Does Rank Kiwi require API keys?

No. Rank Kiwi inspects visible page information directly in your browser without requiring personal API keys.

Can I analyze private profiles?

No. Rank Kiwi only operates on publicly accessible profile grids and channels.

Is there a limit on how many posts I can analyze?

Rank Kiwi allows analyzing 25, 50, 100, or a custom number of posts based on how much content is loaded on the page.
