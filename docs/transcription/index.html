How to Transcribe Instagram Reels Using RankKiwi

RankKiwi lets you extract spoken content from Instagram Reels and convert it into readable text. Generate timestamped transcripts, switch to plain text, copy the result, or download it as a Markdown file.

What is Reel Transcription?

Reel Transcription converts the spoken audio track of an Instagram Reel into accurate, readable written text. By extracting spoken dialogue directly in your browser, RankKiwi enables you to study the exact phrasing, pacing, and hooks behind high-performing short-form video content without having to pause, rewind, or transcribe speech by hand.

Practical Creator Research Use Cases

Content creators, scriptwriters, and video editors use Reel transcription across several everyday workflows:

  • Studying Viral Hooks: Isolate the precise opening 3 to 5 seconds of spoken copy that captured audience retention and sparked the algorithm.
  • Researching Creator Content: Deconstruct how top creators introduce topics, handle mid-video retention dips, and deliver concise value.
  • Understanding Spoken Scripts: Analyze the rhythm, sentence structure, and vocabulary used in videos that beat the creator's median views by 3× to 10×.
  • Saving Useful Information: Preserve step-by-step tutorials, educational explanations, recipe directions, or software walkthroughs directly as readable notes.
  • Analysing Storytelling Techniques: Break down narrative setups, tension shifts, punchlines, and calls to action across various content niches.
  • Building a Content Research Library: Archive spoken scripts as structured Markdown notes in Notion, Obsidian, Bear, or Google Docs for future planning.
  • Repurposing Ideas Into Original Content: Draw inspiration from proven spoken structures to script your own unique, original presentations.

Respect Intellectual Property & Copyright: Transcription is provided strictly as an educational and analytical research tool. Transcribing a Reel does not grant permission to copy, reuse, or redistribute copyrighted audio or spoken scripts without the original creator's explicit consent. Always create original content and respect creator rights.

Configure Your Groq API Key

RankKiwi uses Groq Cloud with the Whisper speech-to-text model to deliver ultra-fast, near-instant transcriptions. Because RankKiwi is client-side and free forever, users connect their own Groq Cloud API key. Follow the three steps below to get set up.

Step 1 — Create a Groq Account

Visit the official Groq Developer Console. If you do not already have an account, click Sign Up to create a free account using your Google, GitHub, or email credentials. Existing users can simply log in.

Step 2 — Generate an API Key

Once signed in to the Groq Developer Console:

  1. Click on API Keys in the left sidebar menu (or navigate directly to console.groq.com/keys).
  2. Click the Create API Key button.
  3. Enter a label to identify your key (for example, RankKiwi Transcription).
  4. Click Submit. Groq will generate your key, which typically begins with the prefix gsk_.
  5. Copy the key immediately to your clipboard.

Security Tip: Treat your API key like a password. Never share it publicly, post it on social media, or commit it to public code repositories. RankKiwi stores your key locally in your browser's private extension storage and sends it directly to Groq's API.

Step 3 — Add the Key to RankKiwi

Adding your key to RankKiwi takes only a moment:

  1. Open any public Instagram Reel in Chrome.
  2. Click the Transcribe Reel button.
  3. When the Connect your Groq API key dialog appears, paste your key into the GROQ API KEY input field.
  4. Click the green Save API Key button.

Your API key is saved in local browser storage (chrome.storage.local). You only need to configure it once in your browser; it will remain active until you clear browser data or replace it. You can update or remove your saved key at any time by clicking the API Key link in the top-right corner of the transcription modal.

Method 1: Transcribe an Individual Reel

When watching a specific Reel on Instagram, you can trigger transcription directly on that video without performing a creator profile analysis.

Step-by-Step Workflow

  1. Open Instagram: Launch Google Chrome with the RankKiwi extension enabled.
  2. Navigate to a Reel: Browse to any creator's Reel or open a Reel URL directly (e.g. instagram.com/reels/[shortcode]/).
  3. Locate the Transcribe Action: RankKiwi injects an overlay button on the top-right corner of the video player labeled Transcribe Reel (accompanied by a document icon).
  4. Click Transcribe Reel: If you have not yet saved your Groq API key, RankKiwi will prompt you to enter it. Once configured, transcription starts immediately.
  5. Monitor Progress: A clean modal appears displaying a loading spinner and status notice: “Transcribing your Reel... Fetching audio and generating transcription with timestamps...”
  6. Read and Use the Transcript: In seconds, the completed transcript appears. Switch between Timestamped and Plain Text views, copy the full text to your clipboard, or click Download as MD to save the file.

Method 2: Transcribe from an Analysed Creator Profile

When conducting deep competitor research, you often analyze a creator's profile first to discover their highest-performing outlier Reels. RankKiwi lets you transcribe any individual outlier Reel directly from the results grid.

Step-by-Step Workflow

  1. Open an Instagram Creator Profile: Navigate to any creator's Reels tab (e.g. instagram.com/[creator]/reels/).
  2. Click Analyze Reels: Click the floating green RankKiwi button at the top-right of the page.
  3. Choose Sample Size: Select 25, 50, 100, or a custom number of recent Reels to scan.
  4. Review the Outlier Grid: Once the client-side scan completes, RankKiwi presents the results modal sorted by Outlier Score.
  5. Select the Outlier Reel to Study: Identify a breakout video (e.g. an outlier scoring 3× or 5× above the creator's median).
  6. Open the Reel and Transcribe: Open the Reel detail view or click the video card's action menu, then select Transcribe video.
  7. Save the Transcript: RankKiwi transcribes that specific Reel. Copy the transcript into your swipe file or download it as Markdown.

Individual, On-Demand Transcription: RankKiwi does not automatically transcribe every Reel during a profile analysis. Transcribing 50 or 100 Reels simultaneously would quickly exhaust API rate limits and slow down your browser. Transcription is always an intentional, individual, user-initiated action for the specific Reels you want to study.

Platform Limitation: The transcription feature is currently supported exclusively for Instagram Reels. YouTube video and Shorts transcription is not currently supported (YouTube channel analytics, Outlier Scores, and HD thumbnail downloads remain fully available).

Understanding Transcript Formats

RankKiwi offers two transcript views inside the transcription interface, allowing you to choose the format that best fits your workflow.

1. Timestamped Transcript

Displays spoken dialogue segmented by exact minute and second time markers. This format is ideal when you need to match spoken phrases to on-screen cuts, study the duration of the hook, or analyze how quickly the creator moves through bullet points.

[00:00] Start your video by walking towards the camera.
[00:02] Start your video by flipping the phone towards yourself
[00:03] on a wide-angle lens.
[00:05] Start your video by putting your phone down and then
[00:07] leaning forward.
[00:08] Start your video by picking your phone up off the ground.

2. Plain-Text Transcript

Presents the entire spoken dialogue as continuous, clean prose with timestamps removed. This view is ideal when you want to read the script like a blog post, paste it into an AI summary assistant, or draft your own version in a document editor.

Copy and Download Transcripts

RankKiwi makes it effortless to transfer transcripts into your existing content planning tools.

One-Click Copy

Click the Copy Transcription button at the bottom of the modal to copy the transcript directly to your clipboard in your currently selected view (Timestamped or Plain Text). A brief confirmation appears, and the text is immediately ready to paste into Notion, Google Docs, Slack, or ChatGPT.

Download as Markdown (.md)

Click the green Download as MD button to save a formatted Markdown file to your computer's downloads folder. Markdown files are lightweight, universal, and easily indexed by note-taking applications like Obsidian, Notion, Bear, Logseq, and VS Code.

The downloaded Markdown file contains clean headers and structured metadata:

# Instagram Reel Transcript
- **Creator:** @brock11johnson
- **Source URL:** https://instagram.com/reels/Dbu46DFAqJy/
- **Generated by:** RankKiwi via Groq Whisper

## Transcript
[00:00] Start your video by walking towards the camera.
[00:02] Start your video by flipping the phone towards yourself...

Troubleshooting & FAQ

If you encounter an unexpected issue while transcribing Reels, review the common solutions below:

Problem Probable Cause & Recommended Solution
API key not accepted Check that your Groq API key was copied completely and begins with gsk_. Ensure there are no accidental spaces before or after the key string.
Transcription fails A temporary network timeout or brief API disruption may have occurred. Click Transcribe Reel again to retry the request.
Audio is unclear or garbled Heavy background music, background noise, low recording volume, or muffled audio can affect AI speech recognition accuracy. Transcription quality naturally depends on the clarity of the original recording.
Reel cannot be transcribed Some Reels contain only silent video, instrumental music with no speech, or private audio tracks that do not expose an audio stream to the browser.
API limit reached You may have reached your Groq Cloud rate limit (requests per minute or tokens per minute). Log in to the Groq Developer Console to check your usage metrics and quota status.
Transcript is incomplete If the video stream was still buffering when transcription was initiated, the audio file may have been truncated. Allow the Reel to play for a couple of seconds, then retry.

Need to update or delete your key? Click the API Key link in the top-right corner of the transcription modal at any time to enter a new key or remove your existing key from browser storage.
